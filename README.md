# Still Rendering

A fictional personal blog by **Tony** spanning 2023–2026: frontend engineering notes woven with questioning his sexuality and coming out over time.

## Run locally

```bash
npm install
npm run dev
```

## Stack

- Vite + React + TypeScript
- React Router
- Hand-written CSS

Eighteen posts live in `src/data/posts.ts`, tagged `frontend`, `personal`, or `mixed`.
